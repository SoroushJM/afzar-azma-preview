JAM3000CT

CT-connected three-phase smart meter

Metering for industrial installations.

JAM3000CT is a three-phase meter connected through current transformers. Developed to FAHAM 1 specifications, it is intended for high-current industrial installations and has modular communication.

Discuss this product

Factories and industrial installations using current-transformer connections.

Capabilities

  • GPRS, G3 and PRIME PLC communication options
  • Control commands for an external relay
  • Records up to 1,000 events
  • Remote tariff programming and firmware updates
